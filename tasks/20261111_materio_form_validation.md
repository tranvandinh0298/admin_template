# Task: Materio Form Validation
**Task ID:** 20261111_materio_form_validation

## Context
Reference: https://demos.themeselection.com/materio-bootstrap-html-admin-template/html/vertical-menu-template/form-validation.html
## Objective
Add the three validation demos to form navigation.
## Scope
### In scope
Browser Default, Bootstrap-style inline feedback, and advanced account, personal and plan validation.
### Out of scope / Non-goals
Backend submission, account creation and file upload.
## Requirements
Use accessible labels and feedback, respect required fields and match passwords in the advanced form.
## Constraints
Prepare rollback records and use local assets.
## Acceptance Criteria
Invalid forms are blocked. Valid forms report demo success. Inline feedback clears as fields are corrected. Layout fits mobile.
## Validation Expectations
Verify invalid/valid transitions, password matching, file selection, reset and navigation.
## Assumptions and Open Questions
Use browser validation primitives for the demo. No blocking questions.
